================================================================================
                  OpenMPTCProuter Optimized - Executive Summary
================================================================================

PROJECT ESSENCE:
A sophisticated multi-WAN bonding router OS that uses MPTCP (Multipath TCP) to
aggregate multiple internet connections (fiber, ADSL, mobile, USB modems) and
encrypts all traffic through a VPS for privacy and redundancy.

================================================================================
                      MULTI-WAN BONDING INTELLIGENCE
================================================================================

FAILOVER MECHANISM: (~50 second timeout)
  1. tcp_keepalive_time: 20 seconds (initial probe)
  2. tcp_keepalive_probes: 3 attempts
  3. tcp_keepalive_intvl: 10 seconds between probes
  4. Total: 20 + (3 × 10) = 50 seconds (vs 375 seconds default)

PATH MONITORING: mptcp-path-manager service
  - Hysteresis: 30-second stability requirement before marking path healthy
  - Blacklisting: 5 failures in 5 minutes = 5-minute blacklist
  - Degradation: 5% loss threshold triggers special handling
  - State files: /var/run/mptcp-paths/interface_name

METRICS COLLECTION: mptcp-metrics-exporter service
  - RTT (round-trip time)
  - Packet loss percentage
  - Jitter variation
  - Signal strength (RSSI, RSRP for modems)
  - Interface statistics
  - Update frequency: 10 seconds

SCHEDULER: BLEST (Bandwidth-Latency-Enabled Scheduling Transfers)
  - Allocates bandwidth proportionally to capacity
  - Prevents slow paths from blocking fast paths
  - Calculates opportunity cost of link utilization

================================================================================
                      DEPLOYMENT WORKFLOW
================================================================================

ROUTER DEPLOYMENT:
  1. Flash image to device (device-specific)
  2. First boot → system runs uci-defaults scripts
  3. Auto-detects WAN ports and modems
  4. Launches web wizard at http://192.168.2.1
  5. Choose pairing method:
     - Auto-discovery: Enter VPS IP
     - Pairing code: Paste code from VPS
     - Manual: Enter all details
  6. credentials → stored in /etc/config/
  7. mptcp-manager service starts
  8. Multi-WAN bonding active

VPS DEPLOYMENT:
  1. Run: curl -sSL https://github.com/.../wizard.sh | sudo bash
  2. Wizard detects OS (Debian/Ubuntu)
  3. Installs packages, optimizes kernel
  4. Generates cryptographically-secure credentials
  5. Configures firewall (allows 65500, 65510, 65520, 8080)
  6. Generates web interface (port 8080)
  7. Saves credentials to /root/openmptcprouter_credentials.txt
  8. shadowsocks-libev-server starts on port 65500
  9. Ready to accept router connections

================================================================================
                        KEY DIFFERENTIATORS
================================================================================

vs Stock OpenWrt:
  ✓ Multi-WAN bonding (not just failover)
  ✓ Intelligent path selection (BLEST scheduler)
  ✓ Automatic USB modem detection
  ✓ Signal strength integration
  ✓ Aggressive failover tuning
  ✓ Pre-configured VPN integration
  ✓ Simplified first-boot wizard

vs Failover-Only Systems:
  ✓ Aggregation (combines bandwidth)
  ✓ Proportional scheduling (faster paths get more traffic)
  ✓ Hysteresis (no flapping)
  ✓ Blacklisting (permanent bad-path removal)
  ✓ Metrics-driven (not just RTT)

vs Proprietary Routers:
  ✓ Open source (GPL v3)
  ✓ Highly configurable
  ✓ Kernel source available
  ✓ Community-driven
  ✓ No vendor lock-in
  ✓ Runs on cheap hardware
